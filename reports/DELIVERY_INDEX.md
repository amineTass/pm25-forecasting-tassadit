# Phase 1 submission

1. `reports/PM25_Phase1_Report.pdf` is the 12-page English technical report.
2. `presentation/` contains the editable PowerPoint, the PDF slide copy, and the speaker guide. Slides 1–14 form the 15-minute talk. The remaining slides are for questions and backup.
3. `reports/PM25_Project_Simple_Explanation.pdf` is the plain-language explanation.
4. `notebooks/01_EDA_and_Preprocessing.ipynb` is the executed exploration and preprocessing notebook.
5. `results/G6_ExtraTrees/` and `results/consolidated/` contain the Phase 1 CSVs and run records.
6. `figures/G6_ExtraTrees/` contains the EDA figures. `folds/G6_ExtraTrees/` contains the frozen folds, overview, and checksums.
7. `src/` contains the pipeline and configuration. `scripts/` contains the launchers, tests, and Git bundle. See `README.md` for execution instructions.

The assignment requires the official `BXX-YY` class code. See the README for how to set it before submission. The source dataset and observation-level tables are recreated by `python -m src.run`.
