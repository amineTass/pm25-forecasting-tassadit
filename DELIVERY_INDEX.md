# Files to use

1. `reports/PM25_Phase1_Report.pdf`: current 12-page technical report.
2. `presentation/PM25_Extra_Trees_Presentation_Final.pptx`: editable deck with speaker scripts and source notes.
3. `presentation/PM25_Extra_Trees_Slides.pdf`: a PDF copy of all 19 slides. Present slides 1-14 in 15 minutes, then use questions and backups as needed.
4. `presentation/PM25_Speaker_and_QA_Guide.pdf`: timings and 12 likely questions/answers.
5. `reports/PM25_Project_Simple_Explanation.pdf`: two-page plain-language explanation.
6. `notebooks/01_EDA_and_Preprocessing.ipynb`: executed exploration and preprocessing.
7. `src/`, `config/`, `tests/`, requirements and launchers: reproducible source.
8. `results/G6_ExtraTrees/` and `results/consolidated/`: results from the current protocol.
9. `repository.bundle`: local Git snapshot of source, configuration, notebook and instructions.
10. `CHANGES.md`: corrections and the boundary between completed first-stage work and later experiments.

Use this complete package in preference to earlier downloaded drafts. Raw source files and observation-level processed tables are recreated by `python -m src.run` and are not redistributed here. The source archive checksum is pinned.
